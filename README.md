# Read Quant Books

Прочитанные (и читаемые) книги по алгоритмическому трейдингу и микроструктуре рынков.

1. **Ernest P. Chan — *Quantitative Trading***  
   Практический гид по построению стратегий с примерами кода на Python и MATLAB.

2. **Ernest P. Chan — *Algorithmic Trading: Winning Strategies and Their Rationale***  
   *В процессе чтения.*

3. **Larry Harris — *Trading and Exchanges***  
   Базовое описание рынка, его участников, регуляции, посредников и микроструктуры на примере американского рынка акций.
